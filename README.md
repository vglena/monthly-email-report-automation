# 📊 Monthly Email Report Automation with Make

This repository contains an independent automation system built with **Make** that generates a **monthly summary report of classified emails**.

The automation queries Gmail using predefined labels, aggregates the results, and sends a consolidated report by email.  
It is designed as a **lightweight reporting system** that operates independently from real-time email processing workflows.

---

## 🎯 Purpose

The purpose of this automation is to:

- Provide visibility into email classification activity
- Generate periodic operational reports
- Avoid manual counting or spreadsheet-based tracking
- Deliver human-readable summaries to stakeholders

---

## 🧩 Automation Overview

The scenario performs the following steps:

1. Query Gmail for emails labeled **Asignada no bancaria**
2. Query Gmail for emails labeled **Nota de control**
3. Query Gmail for emails labeled **Prevalor**
4. Extract the total number of emails per label
5. Generate a consolidated monthly report
6. Send the report automatically by email

---

## 🛠️ Tools and Services

- **Make (Integromat)**
- **Gmail**

---

## 📄 Blueprint

The Make scenario blueprint is available in the `blueprints/` folder and can be imported directly into Make.

---

## 👤 End User

The end user does **not interact with Make**.  
The only user-facing output is the **email report** generated by the automation.

---

## 📌 Notes

- The automation is intended to run on a scheduled basis (e.g. monthly)
- Gmail labels are used as the source of truth
- The system prioritizes simplicity and reliability over granular data processing
